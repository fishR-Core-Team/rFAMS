# Make checks of slot total length value

Make checks of slot total length value

## Usage

``` r
iCheckSlotTL(x, Linf, optname)
```

## Arguments

- x:

  A slot total length value (lower or upper),

- Linf:

  A value of Linf

- optname:

  A name to the error/warning message for when the argument is missing,
  as it is not possible to extract an argument name when the argument is
  missing.
