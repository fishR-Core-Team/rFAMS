# Make checks on life history parameters vector/list

Make checks on life history parameters vector/list

## Usage

``` r
iCheckLHparms(x, optname = NULL)
```

## Arguments

- x:

  a list/vector of seven life history parameters, preferably constructed
  with
  [`makeLH()`](https://fishr-core-team.github.io/rFAMS/reference/makeLH.md)

- optname:

  a name to the error/warning message for when the argument is missing,
  as it is not possible to extract an argument name when the argument is
  missing.
